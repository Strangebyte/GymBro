# Fuentes del historial

Los datos de `tools/seed/gen.py` se cargaron a mano desde documentos que el dueño extrajo de la app del entrenador:

- `ejercicios-gimnasio-sep-nov-2026.md` — inventario de 100 ejercicios y detalle de 32 sesiones (02-09 al 11-11-2026)
- `registro-mesociclo-b.md` — detalle serie por serie (reps, RIR, RPE, peso) de las 11 sesiones del mesociclo B
- `sesiones-nov-13-25.md` — sesiones del 13 al 20-11-2026 y planes del 21 al 28-11 (extraído el 25-11-2026)

Conviene guardar una copia de cada uno acá (este README es lo único de la carpeta que se sube). No hacen falta para compilar ni para desarrollar: todo su contenido útil
ya está volcado en `gen.py`. Sirven para auditar un dato o para rehacer la semilla.

Confianza de esos datos: nombres y series×reps, alta. Pesos, media (se leyeron de capturas de pantalla).
